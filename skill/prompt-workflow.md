# 大模型协作提示词工作流（PYNQ软硬件协同项目）

## 适用场景
使用大模型辅助PYNQ‑Z2项目开发：PS‑PL任务划分、PL逻辑编写、Python驱动调试、DMA排错、撰写测试报告、设计说明书整理；适用于FPGA嵌入式视觉竞赛项目。

## 使用方法
1. 明确给出硬件约束：板卡型号、工作时钟、AXI位宽、DMA MM2S/S2MM位宽、图像分辨率；
2. 清晰界定边界：哪些计算部署PL硬件，哪些业务逻辑保留PS ARM；
3. 附带现有BD框图、代码片段、关键参数，避免模糊需求；
4. 调试阶段附带报错、GPIO读取值、DMA状态寄存器、各环节耗时指标；
5. 模型输出结果必须执行单元测试（小DMA回环、CPU参考路径对比），不可直接交付。

## 失效条件
- 不提供硬件参数直接生成完整工程；
- 跳过小DMA单元测试直接跑完整业务演示；
- 忽略`flush` / `invalidate`缓存同步直接调用DMA；
- 直接采纳模型输出代码，缺少人工审查与测试报告。

## 经验来源
本皮影交互系统开发，大模型辅助逻辑与文档；因缺少硬件约束产生不可运行代码，依靠单元测试修正得到该工作流。
