# 竞赛演示可复现：分阶段准入校验方案

## 适用场景
PYNQ竞赛作品现场演示；解决bit流加载异常、摄像头打开失败、寄存器访问异常；现象为Notebook无输出，故障难以定位。

## 使用方法
1. 四层阶段检查：位流加载校验 → GPIO身份值校验 → 小DMA离线单元测试 → 摄像头设备预检；
2. 增加完整性校验：bit流/HWH文件哈希、开机启动编号，防止混用旧会话、旧位流；
3. 硬件资源独占管理，独立worker进程持有摄像头、DMA、VDMA资源，禁止多进程抢占硬件；
4. 异常策略：校验失败**不自动重试**，保存错误状态；DMA未停止时禁止重载位流；
5. 演示结束流程：停止采集 → 停止DMA → 安全释放缓冲区；保存metrics指标、样本帧、完整执行报告。

## 失效条件
- 跳过分阶段校验直接进入完整业务演示；
- DMA传输未停止就重新加载位流；
- 多进程同时占用摄像头/DMA硬件；
- 异常发生自动循环重试，掩盖底层硬件配置错误。

## 经验来源
皮影交互系统；分阶段检查把现场故障快速定位到位流/GPIO/DMA/摄像头；测试报告与样本用于事后复现核对。
