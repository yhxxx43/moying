# AXI‑DMA与DDR缓存同步踩坑经验

## 适用场景
PYNQ‑Z2使用AXI‑DMA完成PS‑PL大批量图像传输；现象为DMA回读结果随机错乱、图像噪声、计算结果不稳定。

## 使用方法
1. 使用`pynq.allocate()`申请**连续可缓存DMA缓冲区**；
2. PS写发送缓冲区完成后调用`flush()`，再提交DMA传输；
3. DMA传输完成后，接收缓冲区执行`invalidate()`，之后CPU方可读取数据；
4. 先做小规模小DMA单元测试（如17像素向量回环校验），通路确认正确，再跑完整320×240图像帧；
5. 使用`TLAST`标记AXI流结束，软件等待DMA完成状态后再读取结果。

## 失效条件
- 使用普通numpy数组作为DMA缓冲区，物理内存不连续；
- 省略`flush()`、`invalidate()`直接读写DMA缓冲；
- 跳过小规模单元测试，直接跑完整大图；
- 不检查TLAST与DMA完成标志，直接读取结果。

## 经验来源
本项目前期DMA计算结果随机出错；补充显式缓存同步、小DMA单元测试，实现掩膜零差异校验。
