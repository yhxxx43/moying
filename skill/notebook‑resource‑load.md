# Jupyter Notebook资源加载优化技能

## 适用场景
PYNQ Jupyter Notebook演示；美术资源图片Base64嵌入单元格，文件体积大，启动缓慢，首行输出延迟严重。

## 使用方法
1. 将图片、皮影舞台纹理等资源外置为板端本地文件，**禁止大段Base64嵌入Notebook单元格**；
2. 启动时读取资源，增加文件哈希校验，检测资源损坏、缺失；
3. Notebook仅负责预检与人机交互确认；硬件处理逻辑放到独立worker进程，实现硬件独占；
4. 区分Notebook单元格执行耗时、完整系统整机启动耗时两个指标。

## 失效条件
- 将全部皮影舞台纹理、素材以Base64嵌入Notebook；
- 图像采集、DMA处理全部写在Notebook单元格，无独立worker做硬件独占；
- 不校验资源文件完整性。

## 经验来源
项目早期Notebook单元格体积庞大，启动响应慢；资源外置+哈希校验，入口响应速度显著改善。
