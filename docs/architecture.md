# 系统整体架构

整个系统分为PS（ARM处理器）与PL（FPGA逻辑）两大部分。

## PS端（ARM）
1. USB摄像头图像采集，转为灰度图像
2. 将灰度图像通过AXI‑DMA发送至PL端
3. 接收PL处理完毕的剪影图像
4. 完成水墨、剪纸、皮影国风风格渲染
5. 通过AXI‑VDMA推送图像至HDMI输出

## PL端（FPGA硬件逻辑）
1. 接收来自PS的灰度图像
2. 硬件背景差分，提取前景剪影
3. 3×3形态学腐蚀、膨胀降噪处理
4. 处理后的剪影图像经由DMA传回ARM

## 完整数据流
```
摄像头采集 → ARM灰度转换 → AXI‑DMA → PL硬件图像处理 → AXI‑DMA回传PS → 软件国风渲染 → AXI‑VDMA → HDMI显示器输出
```
