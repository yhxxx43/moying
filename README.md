# 墨影随形——基于PYNQ‑Z2的实时国风人体剪影艺术处理系统
> 项目类别：FPGA硬件加速图像处理｜嵌入式艺术可视化
> 硬件平台：PYNQ‑Z2（Zynq‑7020）
> 开发环境：Vivado 2025.2、PYNQ v2.5、Python3.6、OpenCV、NumPy

## 项目简介
本项目面向嵌入式实时图像处理场景，融合FPGA硬件加速与国风数字艺术，实现**摄像头实时人体剪影提取 + 多风格国风渲染输出**。
系统将背景差分、形态学滤波等图像预处理算法部署在FPGA PL端做硬件加速；PS‑ARM端完成图像采集、水墨/剪纸/皮影三种国风艺术渲染，通过HDMI接口实时输出可视化画面。
区别于纯软件图像处理方案，本项目利用Zynq异构架构，把计算密集的像素级预处理迁移到硬件，在保证实时性的同时，实现传统国风美学与嵌入式硬件的结合。

## 创新点
1. **异构架构分工**：PL硬件完成背景差分、腐蚀膨胀形态学降噪，PS负责上层艺术渲染，实现硬件加速与软件灵活算法解耦，提升帧处理速度。
2. **多模式国风渲染**：内置水墨、剪纸、皮影、原始剪影四种可视化模式，可一键切换，将传统民间艺术数字化。
3. **嵌入式端完整闭环**：USB摄像头采集 → PL硬件图像处理 → PS艺术渲染 → HDMI显示输出，整套链路在PYNQ‑Z2开发板上完整运行，无需PC辅助。
4. **可拓展性强**：硬件IP模块可复用，软件渲染模块可独立扩展更多艺术风格。

## 系统总体架构
### 架构划分：PS(ARM) + PL(FPGA)
1. **PS端（ARM处理器）**
- USB摄像头图像采集、灰度预处理
- AXI‑DMA数据交互，向PL发送原始灰度帧，接收硬件处理后的剪影掩码
- 实现水墨、剪纸、皮影国风渲染算法
- AXI‑VDMA驱动，将渲染完成图像推送至HDMI显示

2. **PL端（FPGA硬件逻辑）**
- 背景差分IP：像素级差分运算，分离人体前景与静态背景
- 3×3形态学滤波IP：腐蚀+膨胀，去除剪影椒盐噪声、修补孔洞
- AXI‑DMA：完成PS‑PL之间图像数据流搬运

### 完整数据流
```
USB摄像头采集图像
↓
PS：图像读取、灰度转换
↓
AXI‑DMA → 送入PL硬件
↓
PL：背景差分 → 阈值分割 → 腐蚀 → 膨胀
↓
AXI‑DMA → 剪影掩码回传PS
↓
PS：国风艺术渲染（水墨/剪纸/皮影/剪影）
↓
AXI‑VDMA → HDMI显示控制器
↓
HDMI显示器输出实时画面
```

## 支持渲染风格
修改主程序内`STYLE`参数切换模式：
```python
STYLE = "ink"      # 水墨风格
STYLE = "paper"    # 剪纸风格
STYLE = "puppet"   # 皮影风格
STYLE = "silhoue"  # 原始人体剪影
```
## 快速部署与运行
 
1.环境准备
 
1. SD卡烧录PYNQ‑2.5镜像，插入PYNQ‑Z2开发板上电。
​
2. 网线连接开发板与电脑，配置同网段静态IP，打开Jupyter Notebook网页。
​
3. 将本项目全部文件上传至Jupyter工作目录。
​
4. 硬件接线：USB摄像头接入开发板USB口，显示器接HDMI‑OUT接口。
 
2.运行项目
 
进入项目目录，执行主程序：
```
%run complete_camera_hdmi.py
```
3.停止程序
 
Jupyter Notebook内核点击【Interrupt】中断脚本。
